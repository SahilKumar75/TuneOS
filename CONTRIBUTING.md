# Contributing to Finetune Platform

Thank you for your interest in contributing to the Finetune Platform! We welcome contributions from the community.

## Getting Started

1. Fork the repository and clone it locally.
2. Install dependencies:
   ```bash
   poetry install
   ```
3. Set up your environment variables by copying `.env.example` to `.env`.
4. Run the full stack locally using `docker-compose up` or start components individually.

## Pull Requests

1. Create a new branch for your feature or bugfix.
2. Ensure your code passes all tests and linting.
3. Submit a pull request with a clear description of the changes.

## Issues

If you find a bug or have a feature request, please open an issue on the GitHub repository.
