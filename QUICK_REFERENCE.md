# Quick Reference Guide

## What Changed?

### Before ❌
- Static 5 questions that never changed
- Questions same for everyone (healthcare, finance, code - all identical)
- No feedback until end
- Basic UI design
- Synthetic data had poor error handling
- User had to guess if plan made sense

### After ✅
- **Dynamic questions** generated by AI based on your project
- **Personalized** to your domain (healthcare questions for healthcare projects)
- **Live plan updates** show what you're building as you answer
- **iOS-style UI** with smooth animations and modern design
- **Reliable data generation** with multiple fallbacks
- **Clear feedback** at every step

## Setup (One Time)

```bash
# 1. Add to .env file
echo "OPENROUTER_API_KEY=sk-or-v1-your-key-here" >> .env

# 2. Restart your app
reflex run
```

Get free API key: https://openrouter.ai/

## How to Use

### Step 1: Describe Your Project (Phase A)
```
Fill out:
• Project Name (e.g., "Customer Support Bot")
• Description (e.g., "Answer common questions about our product")
• Use Case (Personal or Company)
• Domain (e.g., Customer Service)
• Task Type (e.g., Text)

Click: "Continue to Questions" →
```

### Step 2: Answer Smart Questions (Phase B)
```
• AI generates 5 relevant questions
• Answer each one (or choose "Other" for custom)
• See your plan update in real-time
• Progress through all 5 questions

Example for healthcare project:
Q: "What level of medical accuracy is required?"
Options:
  ○ General health information
  ● Clinical-grade accuracy  ← Your answer
  ○ Patient education level

Live Plan appears:
💡 "A healthcare model that provides clinical-grade 
   diabetes management information..."
```

### Step 3: Review & Approve (Phase C)
```
• See complete summary
• Edit if needed
• Approve to continue
```

## Troubleshooting

### Questions Not Personalized?

**Check:**
```bash
# Is API key set?
grep OPENROUTER_API_KEY .env

# Should show:
OPENROUTER_API_KEY=sk-or-v1-...
```

**If missing:** Add key, restart app

**If present:** Check console logs for errors

### Plan Not Updating?

**Normal:** Feature is optional, flow works without it

**Check:** Browser console for errors

**Fix:** Verify API key is valid

### Data Generation Failing?

**Check response stats:**
```json
{
  "generation_method": "openrouter",  // ✓ Good
  "generation_method": "template",    // ✗ Fallback
  "errors": ["OpenRouter failed: ..."] // Debug info
}
```

**Common issues:**
- No API keys set → Uses templates (still works)
- Rate limit hit → Try again in a moment
- Invalid format → Check console logs

## API Usage

### Question Generation (Phase A → B)
```python
# Automatically called when user clicks "Continue"
await _generate_personalized_questions()

# Uses: deepseek/deepseek-v4-flash:free
# Takes: 2-5 seconds
# Returns: 5 personalized questions
```

### Plan Updates (After Each Answer)
```python
# Automatically called after each answer
await _update_live_plan()

# Uses: deepseek/deepseek-v4-flash:free
# Takes: 1-2 seconds
# Returns: Short summary (2-3 sentences)
```

### Synthetic Data (Manual Trigger)
```python
# User clicks "Generate Data"
POST /datasets/generate

# Tries: OpenRouter → HuggingFace → Templates
# Returns: {samples, path, stats}
```

## State Variables Quick Lookup

```python
# Phase tracking
intent_phase                    # 1, 2, or 3

# Phase A: Context
intent_project_name             # string
intent_description              # string
intent_use_for                  # "personal" | "company"
intent_domain                   # "healthcare" | "finance" | ...
intent_task_type                # "text" | "vision" | ...

# Phase B: Dynamic questions
intent_questions                # list[dict] - AI generated
intent_question_idx             # int - current question (0-4)
intent_answers                  # list[str] - user's selections
intent_is_generating_questions  # bool - loading state
intent_live_plan                # string - real-time summary

# Phase C: Final
intent_md                       # string - full markdown
intent_approved                 # bool
```

## Event Handlers Quick Lookup

```python
# Phase navigation
intent_next_phase()             # Advance phase, generate questions
intent_prev_phase()             # Go back

# Phase B navigation
intent_next_question()          # Next question or finish
intent_prev_question()          # Previous question

# Answer handling
set_intent_answer(idx, value)   # Select option, update plan
toggle_intent_custom(idx)       # Show/hide custom input
set_intent_custom_answer(idx, value)  # Type custom answer

# Final
approve_intent()                # Finish wizard
```
