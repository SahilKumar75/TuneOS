#  TuneOS Intent Flow - Major Update

## What's New?

Your TuneOS fine-tuning wizard just got a massive upgrade! Say goodbye to generic questions and hello to a personalized, intelligent experience powered by AI.

###  Key Improvements

1. ** AI-Generated Personalized Questions**
   - Questions adapt to YOUR project (healthcare, finance, education, etc.)
   - OpenRouter API generates relevant, context-aware questions
   - No more one-size-fits-all approach

2. ** Live Plan Updates**
   - See your plan evolve as you answer questions
   - Real-time feedback keeps you on track
   - Know exactly what you're building

3. ** Beautiful iOS-Style UI**
   - Modern, polished design inspired by iOS
   - Smooth animations and transitions
   - Better visual hierarchy and spacing

4. ** Reliable Data Generation**
   - OpenRouter  HuggingFace  Templates fallback chain
   - Better error handling and debugging
   - Higher quality synthetic data

5. ** Enhanced Context Collection**
   - Project name and description fields
   - More domain options (added Technology)
   - Better organized with clear labels

##  Quick Start

### 1. Get Your API Key (2 minutes)

```bash
# Visit OpenRouter and sign up (free)
https://openrouter.ai/

# Get your API key from dashboard
# Add to your .env file:
echo "OPENROUTER_API_KEY=sk-or-v1-your-key-here" >> .env
```

### 2. Restart Your App

```bash
# Stop if running
# Then restart
reflex run
```

### 3. Try It Out!

Navigate to the Fine-tune wizard and:
- Fill out your project details
- Click "Continue to Questions"
- Watch AI generate personalized questions
- Answer questions and see your plan update live
- Review and approve your intent

**That's it!**

##  Configuration

### Required Environment Variable

```bash
OPENROUTER_API_KEY=sk-or-v1-your-key-here
```

### Optional (for data generation fallback)

```bash
HF_TOKEN=hf_your_huggingface_token
```

### Graceful Degradation

**Without API key:**
-  Flow still works
-  Uses default questions
-  Data generation uses templates
-  Less personalized experience

**With API key:**
-  Personalized questions
-  Live plan updates
-  High-quality data generation
-  Best experience

##  Known Issues & Solutions

### Issue: Questions not personalized

**Cause:** API key not set or invalid

**Solution:**
```bash
# Check if key is set
env | grep OPENROUTER_API_KEY

# Set it in .env
echo "OPENROUTER_API_KEY=your-key" >> .env

# Restart app
```

### Issue: Plan not updating

**Cause:** API timeout or error

**Solution:**
- Check browser console for errors
- Feature is optional - flow continues without it
- Verify network connectivity

### Issue: Synthetic data quality low

**Cause:** Falling back to templates

**Solution:**
- Set OPENROUTER_API_KEY for best quality
- Or set HF_TOKEN for medium quality
- Templates work but are basic
