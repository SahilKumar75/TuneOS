# Quickstart

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SahilKumar75/TuneOS
   cd TuneOS
   ```

2. **Set up Environment Variables:**
   ```bash
   cp .env.example .env
   # Add your Hugging Face Token to the HF_TOKEN variable
   ```

3. **Start the Platform:**
   ```bash
   docker-compose up -d
   ```

4. **Access the App:**
   Open http://localhost:3000 in your browser to access the finetuning dashboard.
