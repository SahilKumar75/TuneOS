Balanced Binary Trees

Calculate the number of balanced binary trees possible for a given height, modulo 1000000007.

Total Balanced Trees
0
// Core Logic const mod = 1000000007n; let dp = new Array(n + 1); dp[0] = 1n; dp[1] = 1n; for (let i = 2; i <= n; i++) { let prev1 = dp[i - 1]; let prev2 = dp[i - 2]; let bothMinusOne = (prev1 * prev1) % mod; let oneMinusTwo = (2n * prev1 * prev2) % mod; dp[i] = (bothMinusOne + oneMinusTwo) % mod; }
